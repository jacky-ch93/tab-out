谷歌账户同步

正在检查 Chrome 同步账户…

请在 Chrome 中完成登录和同步设置。本插件使用浏览器账户，不会弹出单独的谷歌登录窗口。

若设置页没有打开，请复制以下地址到 Chrome 地址栏并回车：

chrome://settings/syncSetup

登录后开启同步，并在「管理同步内容」中启用「扩展程序」。完成后回到这里，点击「重新检查账户」。

正在读取云端副本…

上传覆盖云端；下载覆盖本地；合并按网址取并集，同网址保留本地名称和顺序。下载和合并不会改动云端。

请在各设备登录同一 Chrome 账户并开启扩展程序同步。读取的是 Chrome 已同步到本机的云端副本，跨设备更新可能稍有延迟。

识别到账户不代表云端传输已经开启。账户权限、未登录或尚无副本的问题会显示具体提示，不会静默禁用按钮。
